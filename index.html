GeoDash Pro Guide

1 KML to CSV Conversion

  • Structure: Extracts Geometries (Point, LineString, Polygon) into WKT.
  • Hierarchy: Automatically maps your KML folder structure into dynamic CSV columns (folder_1 is closest to the object).
  • Measurements: Toggle "Calculate Lengths" to automatically generate a measurement column using the Haversine formula.

2 CSV to KML Conversion

  • Formatting: Your CSV must contain a wkt column and optional name / description columns.
  • Rebuilding Folders: Includes columns like folder_1, folder_2, etc. GeoDash will flawlessly rebuild the original nested KML directory tree top-down!

3 Style Settings

  • Click the Style button (top-right) to customize label size, point icon (color/scale), and line color/weight.
  • These settings are written into the generated KML's <Style> blocks (visible in Google Earth) and are also reflected live in the map preview below.
